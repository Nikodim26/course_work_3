# Виджет банковских операций клиента
## Данный проект предназначен для предоставления информации по банковским операциям клиента
Проект позволяет, используя данные из файла *.XLSX, получить JSON строки для фронтенда.
Позволяет вычислить выгодные категории кешбэка, получить список трат по категории за три предыдущих месяца от заданной
даты или от текущей.
## Установка
Проект можно скачать архивом с GitHub и использовать при помощи PyCharm. *.exe пока нет
## Использование
Диалог с клиентом предполагается после разработки фронтенда
Функция main - основная. Позволяет по принятой дате ввиде строки в формате YYYY-MM-DD HH:MM:SS и необязательному
параметру ввиде периода возврата назад во времени на неделю, месяц, год, что соответствует:
неделя - значит с недельной давности по заданную дату
месяц - значит с начала месяца относительно заданной даты по заданную
год - значит с начала года относительно заданной даты по заданную


Функция working_with_transactions_period()
Позволяет считать данные из *.XLSX, исключить неинтересные данные, отформатировать некоторые данные, создав таким 
образом копию базы для дальнейшего извлечения информации. Также создает кэш курсов валют, присутствующих в перечне
банковских операций.

Функция determining_the_phase_of_the_day()
Позволяет определить время суток и выдать приветствие - Добрые: утро, день, вечер или ночь по заданному шаблону

Функция currency_conversion()
Используя API, позволяет узнавать курсы валют, присутствующих в перечне банковских операций.

Функции working_with_transactions() и working_with_transactions_events()
Позволяют формировать JSON для фронтенда двух видов.

Функция recording_card_numbers()
Формирует список банковских карт, присутствующих в перечне банковских операций.

Функция recording_exchange_rates()
Формирует запись о курсах валют, заданных отдельно.

Функция recording_stock_quotes()
Формирует список котировок акций, заданных отдельно.

Функция record_of_replenishments()
Формирует запись пополнений, присутствующих в перечне банковских операций.

Все значения выражены в рублях, используя API текущих курсов валют.
